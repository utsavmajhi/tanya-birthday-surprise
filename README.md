# Birthday Surprise Website

Open `index.html` in a browser to preview the surprise.

## Customize Fast

1. Replace the letter text in `index.html`.
2. Her photos are already copied into `assets/images/tanya-01.jpeg` through `tanya-12.jpeg`.
3. Her songs are already copied into `assets/music`.
4. `BirthdayBackgroundSong.mp3` plays as the looping background song after the first tap or the music button.
5. The Amazon gift card reveal is in the `#gift` section of `index.html`.
6. Edit the memory captions, song names, and quiz answers at the top of `script.js`.

## Quiz Answers

The default unlock answers are in `script.js`:

```js
const answers = {
  color: "pink",
  place: "home",
  nickname: "baby",
};
```

Change these before sending the site to her.
